# Portfolio publication gate

Do not publish a model-accuracy claim until the experiment uses a documented official snapshot and the final chronological test set has been evaluated once.

Before posting:

- replace demo screenshots with real-data dashboard screenshots;
- add the snapshot date range and row count;
- report baseline and ML results together;
- show at least one failure case and limitation;
- link the live demo only after secrets and endpoints are secured;
- complete the review questions in `docs/INTERVIEW_GUIDE.md`.
