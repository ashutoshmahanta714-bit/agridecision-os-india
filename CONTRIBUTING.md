# Contributing

1. Create a focused branch.
2. Add or update tests for every behaviour change.
3. Run `python -m pytest` and `python -m ruff check src tests`.
4. Keep secrets, raw data, model files, and generated metrics out of commits.
5. Document data lineage and licence for every new source.
6. Never convert synthetic metrics into real-world claims.
7. Use chronological evaluation for time-dependent predictions.
